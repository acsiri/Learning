================================================================================
STEP 3: DEBUG CONTROLS
================================================================================

While debugging:
  F10  = Step Over (next line, don't enter functions)
  F11  = Step Into (enter functions)
  Shift+F11 = Step Out (exit current function)
  F5   = Continue (jump to next breakpoint)
  Shift+F5 = Stop debugging

================================================================================
TROUBLESHOOTING
================================================================================

❌ Breakpoints not working?
  → File not saved - Press Ctrl+S
  → Restart debugger - Shift+F5 then F5
  → Check Python extension is installed

❌ Debug console not showing?
  → Click View → Debug Console
  → Or press Ctrl+Shift+Y

❌ Can't find Run & Debug?
  → Click Run icon (▶️) on left sidebar
  → Or press Ctrl+Shift+D
